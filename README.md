# 滑板人生 - 3D 霓虹跑酷

🛹 一个热带风格的 HTML5 3D 滑板闯关游戏

## 游戏玩法

- **目标**：控制滑板小人躲避障碍物，到达终点
- **操作**：← → 方向键、A/D 键 或 虚拟按钮控制移动
- **得分**：躲避障碍物 + 跑酷距离
- **暂停**：按 ESC 键或点击暂停按钮

## 全新特性

- **8 大主题关卡**：粉色浪漫、热带夏日、森林氧吧、极简黑白、星空宇宙、冰雪奇缘、沙漠黄昏、赛博朋克
- **音效系统**：背景音乐、碰撞音效、金币收集、关卡升级
- **存档系统**：最高分、各难度最佳成绩、累计金币
- **视觉特效**：动态阴影、摄像机晃动、霓虹光效
- **触控支持**：手机端虚拟方向按钮

## 视觉主题

- **赛博朋克风格**
  - 主色调：青色(#0ff)、品红(#f0f)
  - 背景：霓虹渐变天空
  - 地面：金属质感反射

## 平台支持

- ✅ **Web 端**: https://skate-life.pages.dev/（Cloudflare Pages 部署）
- 🔜 **Android**: 计划中

## 技术

- Three.js 3D 渲染
- Web Audio API 音效合成
- Canvas 2D / WebGL
- 响应式设计（适配手机和桌面）

## 运行

直接在浏览器中打开 `index.html` 即可游玩。
